## 目标
让 markdown 中的代码块按语言类型用不同样式（语法高亮）渲染，并附带语言标签和复制按钮。仅改渲染端，不改后端、不改编辑器。

## 方案概览
集成 `prism-react-renderer`（v2）。在 `MarkdownRender` 里覆盖 `code`（区分行内/块）和 `pre`（透传，避免嵌套 `<pre>`），新增一个 `CodeBlock` 组件负责高亮渲染、语言标签、复制按钮。选 `vsDark` 主题，其背景色 `#1e1e1e` 与现有 `.markdown-body pre` 完全一致，视觉无缝。

## 依赖
在 `frontend/package.json` 增加：
- `prism-react-renderer` ^2.4.1（高亮 + 主题）
- `prismjs` ^1.29.0（仅用于注册额外语言语法的 `prismjs/components/prism-xxx`）
- `@types/prismjs` ^1.26.0（devDependencies，类型）

prism-react-renderer v2 内置常用语言（js/ts/tsx/jsx/python/go/bash/sql/json/yaml/css/markdown/diff/c/cpp 等），但**不含 Rust**。这是 Rust 社区，所以额外注册：`rust, java, kotlin, swift, php, ruby, docker, toml, ini`（均可扩展）。

## 文件改动

### 1. 新增 `frontend/src/components/markdown/prismLanguages.ts`
注册额外语言。采用 prism-react-renderer 官方文档的 top-level await 模式（Vite 支持 TLA）：
```ts
import { Prism } from 'prism-react-renderer'
// 把 prism-react-renderer 的 Prism 实例挂到全局，
// 这样 prismjs 的语法包会注册到同一个实例上
;(globalThis as any).Prism = Prism

await import('prismjs/components/prism-rust')
await import('prismjs/components/prism-java')
await import('prismjs/components/prism-kotlin')
await import('prismjs/components/prism-swift')
await import('prismjs/components/prism-php')
await import('prismjs/components/prism-ruby')
await import('prismjs/components/prism-docker')
await import('prismjs/components/prism-toml')
await import('prismjs/components/prism-ini')

export { Prism }
```
> 必须用 `await import`：静态 import 会在赋值 `globalThis.Prism` 之前执行（ESM 导入提升），导致语法包找不到 Prism 实例。

### 2. 新增 `frontend/src/components/markdown/CodeBlock.tsx`
```tsx
import { useState } from 'react'
import { Highlight, themes } from 'prism-react-renderer'
import { Copy, Check } from 'lucide-react'
import './prismLanguages' // 副作用：注册额外语言

interface CodeBlockProps {
  code: string
  language: string
}

export default function CodeBlock({ code, language }: CodeBlockProps) {
  const [copied, setCopied] = useState(false)

  const handleCopy = async () => {
    try {
      await navigator.clipboard.writeText(code)
      setCopied(true)
      setTimeout(() => setCopied(false), 2000)
    } catch {
      // 忽略复制失败
    }
  }

  return (
    <div className="code-block">
      {/* 头部：语言标签 + 复制按钮 */}
      <div className="code-block__header">
        <span>{language || 'text'}</span>
        <button onClick={handleCopy} className="code-block__copy">
          {copied ? <Check className="h-3.5 w-3.5" /> : <Copy className="h-3.5 w-3.5" />}
          {copied ? '已复制' : '复制'}
        </button>
      </div>
      {/* 高亮主体 */}
      <Highlight theme={themes.vsDark} code={code} language={language || 'text'}>
        {({ style, tokens, getLineProps, getTokenProps }) => (
          <pre style={style}>
            {tokens.map((line, i) => {
              const { key, ...lineProps } = getLineProps({ line })
              return (
                <div key={i} {...lineProps}>
                  {line.map((token, k) => {
                    const { key: tk, ...tokenProps } = getTokenProps({ token })
                    return <span key={k} {...tokenProps} />
                  })}
                </div>
              )
            })}
          </pre>
        )}
      </Highlight>
    </div>
  )
}
```
> 注意 prism-react-renderer v2 的 `getLineProps`/`getTokenProps` 会返回 `key`，需从展开中剥离（否则 React 警告）。

### 3. 修改 `frontend/src/components/MarkdownRender.tsx`
在 `components` 映射里增加 `pre` 和 `code` 覆盖：
```tsx
import CodeBlock from './markdown/CodeBlock'

// ...在 components 对象中：
// pre 透传：避免外层再包一层 <pre>（CodeBlock 自带 <pre>）
pre: ({ children }) => <>{children}</>,
// code：区分行内与块
code: ({ className, children, ...props }) => {
  const text = String(children ?? '')
  const match = /language-(\w+)/.exec(className || '')
  // 有 language-xxx，或文本含换行（无语言围栏块）→ 视为块级代码
  const isBlock = !!match || text.includes('\n')
  if (!isBlock) {
    // 行内代码：沿用 .markdown-body code 的胶囊样式
    return <code className={className} {...props}>{children}</code>
  }
  return <CodeBlock code={text.replace(/\n$/, '')} language={match?.[1] || ''} />
},
```
判断逻辑说明（react-markdown v9 不再传 `inline`）：
- 行内 `` `code` ``：无 className、无换行 → 行内胶囊样式
- 无语言围栏块 ` ```\ncode\n``` `：无 className 但有换行 → 块级渲染
- 带语言围栏 ` ```js\ncode\n``` `：有 `language-js` → 块级渲染

### 4. 修改 `frontend/src/index.css`
在现有 `.markdown-body pre` 规则后增加 `.code-block` 作用域样式，避免主题内联样式与旧规则冲突：
```css
/* 代码块容器：圆角 + 裁剪头部圆角 */
.markdown-body .code-block {
  margin: 1em 0;
  border-radius: 8px;
  overflow: hidden;
  border: 1px solid #333;
}

/* 头部条 */
.markdown-body .code-block__header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 6px 12px;
  background: #2d2d2d;
  color: #9da5b4;
  font-size: 0.75em;
  font-family: 'SF Mono', Consolas, Menlo, monospace;
  text-transform: lowercase;
}

/* 复制按钮 */
.markdown-body .code-block__copy {
  display: inline-flex;
  align-items: center;
  gap: 4px;
  background: transparent;
  border: none;
  color: #9da5b4;
  cursor: pointer;
  font-size: inherit;
  font-family: inherit;
  padding: 2px 6px;
  border-radius: 4px;
}
.markdown-body .code-block__copy:hover {
  background: rgba(255, 255, 255, 0.08);
  color: #d4d4d4;
}

/* Highlight 渲染的 <pre>：去掉外层 pre 的圆角/外边距，主题内联样式接管背景色 */
.markdown-body .code-block pre {
  margin: 0;
  border-radius: 0;
  padding: 16px;
  font-size: 0.85em;
}
```
保留现有 `.markdown-body pre` / `pre code` 规则不动（作为兜底；新规则用更高特异度覆盖圆角/边距）。

## 验证
1. `npm install`（安装新依赖）
2. `npm run lint`（tsc --noEmit，确认类型无误，含 TLA）
3. `npm run build`（确认 vite 构建通过）
4. 人工：`npm run dev`，在含代码块的帖子里查看：带语言（js/rust/go 等）的高亮、无语言围栏块、行内 `code` 的胶囊样式、语言标签显示、复制按钮可用。

## 影响范围
- 渲染端：`MarkdownRender.tsx`、新增 `CodeBlock.tsx`、`prismLanguages.ts`、`index.css`
- 消费方（`Forum/TopicDetail.tsx`、`Community/Detail.tsx`）无需改动，自动生效
- 不改后端、不改编辑器、不改数据结构
