# 去掉 antd，迁移到 Tailwind + 轻量方案

## 目标
一次性全量迁移：删除 antd 与 @ant-design/icons，改用 **Tailwind CSS v3 + @headlessui/react + @tanstack/react-table + react-hook-form + sonner + lucide-react**。迁移完成后代码库无 antd 残留，可独立运行。

## 新增依赖
| 包 | 用途 | 替代 |
|----|------|------|
| `tailwindcss` + `postcss` + `autoprefixer` | 原子化样式 | antd 内置样式 |
| `@headlessui/react` | Dialog/Menu/Dropdown/Popover/Combobox | antd Modal/Dropdown/Select/Tabs/Popconfirm(部分) |
| `@tanstack/react-table` | headless 表格 | antd Table |
| `react-hook-form` + `zod` + `@hookform/resolvers` | 表单状态与校验 | antd Form + rules |
| `sonner` | toast 通知 | antd message |
| `lucide-react` | 图标库 | @ant-design/icons |

> 已有依赖保留：react 18、react-router-dom 7、axios、dayjs、zustand、react-markdown、remark-gfm。

## 删除依赖
- `antd`
- `@ant-design/icons`

## 实施步骤

### 第 1 步：基础设施搭建
1. 安装上述新依赖；移除 antd 与 @ant-design/icons。
2. 初始化 Tailwind：创建 `tailwind.config.js`（content 指向 `src/**/*.{ts,tsx}`、`index.html`）、`postcss.config.js`。
3. 改写 `src/index.css`：顶部加 Tailwind 三件套指令（`@tailwind base/components/utilities`），保留现有全局 reset 与 markdown 样式。在 `tailwind.config.js` 的 `theme.extend` 里定义设计 token：
   - `colors.primary = '#ce422b'`（沿用 Rust 主题色）及 primary-50…900 色阶
   - `borderRadius` 默认 6px
   - `fontSize` 基准 15px
4. 删除 `vite.config.ts` 中 `manualChunks` 里的 `antd` 与 `icons` 两个 chunk（保留 `react-vendor`），避免构建引用不存在的包。
5. 删除 `main.tsx` 中的 `ConfigProvider` / `AntApp` / `zhCN` 包裹，改为直接渲染 `<App />`（dayjs 中文 locale 保留）。

### 第 2 步：封装基础 UI 组件（`src/components/ui/`）
用 Tailwind 封装一组与 antd 用法接近的组件，供页面替换时直接对应：
- `Button.tsx`：variant（primary/default/danger/text/link）+ size（small/middle/large）+ loading + block + icon。
- `Input.tsx` / `Textarea.tsx`：支持 prefix、size、allowClear、disabled；`Input.Password` 用 headlessui 或原生 type=password + 显隐按钮。
- `Select.tsx`：基于 headlessui `Combobox` 或 `Listbox`，支持单选/多选（mode="multiple"）、allowClear、options。
- `Tag.tsx`：color 映射（default/blue/red/green/orange…）→ Tailwind class。
- `Avatar.tsx`：src / fallback 文字 / icon。
- `Space.tsx`：flex 容器（direction/size/wrap）。
- `Card.tsx`：标题 + body。
- `Spin.tsx` / `Loading.tsx`：旋转加载。
- `Empty.tsx` / `EmptyState.tsx`：空状态。
- `Divider.tsx`：分隔线（含"或"文字分隔）。
- `Typography.tsx`：Title/Text/Paragraph（level 映射 h1-h5，type=secondary）。
- `Pagination.tsx`：分页器（current/total/pageSize/onChange/showTotal）。
- `Modal.tsx`：基于 headlessui `Dialog` + portal + transition，API 对齐（open/onOk/onCancel/title/okText/cancelText）。
- `Tabs.tsx`：基于 headlessui `Tab`，对齐 activeKey/onChange/items。
- `Dropdown.tsx`：基于 headlessui `Menu`。
- `Radio.tsx`：Radio.Group。
- `InputNumber.tsx`：数字输入。
- `Alert.tsx`：错误提示条（type=closable）。
- `Statistic.tsx`：统计数字。
- `Result.tsx`：404/结果页。

同时封装：
- `MessageProvider`：在 `App.tsx` 顶层挂 `<Toaster />`（sonner），导出 `toast` 兼容 `message.success/error/info/warning`。
- 改写 `utils/messageHolder.ts`：`getMessage()` 返回一个封装 `toast` 的适配对象（success/error/info/warning/loading），保持 `api/client.ts` 调用不变。
- `ConfirmButton.tsx`：替代 Popconfirm 的内联确认组件——点击后按钮原地切换为"确认/取消"两步，onConfirm 触发。

### 第 3 步：迁移页面与布局（25 个文件，按依赖顺序）
顺序：基础设施页 → 布局 → 列表页 → 详情/创建页 → Admin。

1. **入口/全局**：`main.tsx`、`App.tsx`（移除 AntApp.useApp，挂 Toaster）、`utils/messageHolder.ts`、`api/client.ts`（删除 `import { message as staticMessage } from 'antd'`，`msg()` 改用 messageHolder）。
2. **布局**：`layouts/MainLayout.tsx`（Layout/Header/Sider/Content→div+Tailwind；Menu→自写导航；Dropdown→headlessui）、`layouts/AuthLayout.tsx`。
3. **公共组件**：`components/Loading.tsx`、`EmptyState.tsx`、`MarkdownRender.tsx`（MarkdownRender 不依赖 antd，仅核对）。
4. **auth**：`Login.tsx`、`Register.tsx`、`GitHubCallback.tsx`——Form→react-hook-form + zod（含确认密码跨字段校验，用 zod 的 `.refine`）。
5. **列表页**：`Home.tsx`、`Forum/List.tsx`、`QA/List.tsx`、`Article/List.tsx`、`Resource/List.tsx`、`Community/List.tsx`、`NotFound.tsx`——Card/List/Pagination/Tag→新组件。
6. **详情/创建页**：`Forum/TopicDetail.tsx`、`Community/Detail.tsx`、`Topic/Create.tsx`（含原生 input file 上传，保留逻辑、换样式）、`Community/Create.tsx`、`User/Profile.tsx`（Form→react-hook-form）。
7. **Admin**：`Admin/Users.tsx`（Table→tanstack/react-table + 自定义分页；Modal；Tabs）、`Admin/Categories.tsx`（Table + Modal + Form→react-hook-form；Select multiple）、`Admin/Moderators.tsx`。

每个文件迁移要点：
- `import {...} from 'antd'` → 改为从 `@/components/ui/*` 引入对应组件。
- `import {...} from '@ant-design/icons'` → `import {...} from 'lucide-react'`，按名字映射（如 `UserOutlined`→`User`、`HomeOutlined`→`Home`、`SearchOutlined`→`Search`、`GithubOutlined`→`Github`、`EditOutlined`→`Pencil`/`SquarePen` 等）。
- 内联 `style={{...}}` 尽量转为 Tailwind class；复杂动态样式保留 style。
- `ColumnsType<T>`（来自 `antd/es/table`）→ tanstack 的 `ColumnDef<T>`。
- antd `Form.useForm` / `validateFields` / `setFieldsValue` / `resetFields` → react-hook-form 的 `useForm` / `handleSubmit` / `setValue` / `reset`，zod schema 做校验。
- `message.success(...)` → `toast.success(...)`（经 messageHolder 适配后调用处可不变，但顺手统一为 toast）。

### 第 4 步：清理与验证
1. 全局搜索确认无 `antd`、`@ant-design`、`antd/es/`、`ConfigProvider`、`AntApp` 残留引用。
2. `npm run lint`（tsc --noEmit）通过，无类型错误。
3. `npm run build` 通过，检查打包产物不再含 antd chunk。
4. 人工/截图核对关键页面视觉：首页、登录/注册、论坛列表与详情、发帖、Admin 三个表格、个人中心。
5. 更新 `README.md` 中前端技术栈说明（antd → Tailwind + headlessui 等）。

## 风险与对策
- **视觉一致性**：antd 组件有默认间距/字重，Tailwind 重写会有细微差异。对策：基础组件尽量贴近原视觉，迁移后统一走查；保留 Rust 主题色与圆角 token。
- **react-hook-form 与原 Form API 差异较大**：Register 的确认密码 validator、Categories 的 `setFieldsValue` 回填是重点。对策：zod `.refine` 处理跨字段；`setValue` 逐字段回填。
- **Select multiple + Table 分页** 是较复杂点。对策：Select 用 headlessui Listbox multiple；Table 用 tanstack 手动分页（项目原本就是手动分页，直接复用 page 状态）。
- **中间不可运行**：一次性迁移期间构建会失败，直到最后清理完成。对策：按步骤顺序推进，最后统一 `tsc` + `build` 验证；不中途提交半成品。
