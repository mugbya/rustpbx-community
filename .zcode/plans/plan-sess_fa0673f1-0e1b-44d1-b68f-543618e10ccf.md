# 文章目录（TOC）导航功能实现计划

为文章（`topic.type === 'article'`）详情页增加右侧粘性目录导航：自动从正文中提取标题，点击跳转到对应章节，滚动时高亮当前所在章节。仅在大屏（`lg` ≥1024px）显示。

不新增任何 npm 依赖（沿用已安装的 `react-markdown` 自定义组件能力）。

## 涉及文件

| 文件 | 操作 | 说明 |
|---|---|---|
| `frontend/src/utils/slug.ts` | 新建 | slug 生成 + `TocHeading` 类型 |
| `frontend/src/components/MarkdownRender.tsx` | 编辑 | 给标题加 id + 暴露 `onHeadings` 回调 |
| `frontend/src/components/Toc.tsx` | 新建 | 粘性目录组件（含 scroll spy） |
| `frontend/src/pages/Forum/TopicDetail.tsx` | 编辑 | 文章类型下加右侧栏布局 + 接入 TOC |
| `frontend/src/index.css` | 编辑 | 标题加 `scroll-margin-top`（兜底） |

## 1. `frontend/src/utils/slug.ts`（新建）

```ts
// 目录条目
export interface TocHeading {
  id: string
  text: string
  level: number // 1-4
}

// 将标题文本转成 url 安全的 slug
export function slugify(text: string): string {
  return text
    .trim()
    .toLowerCase()
    .replace(/[^\p{L}\p{N}\s-]/gu, '') // 保留字母/数字/空格/连字符，支持中文(\p{L})
    .replace(/\s+/g, '-')
    .replace(/-+/g, '-')
    .replace(/^-|-$/g, '')
}
```

用 `Unicode property escapes`（`\p{L}`、`\p{N}`）保留中文/日文等字符，与 GitHub slug 行为接近；空标题回退为 `heading`。

## 2. `frontend/src/components/MarkdownRender.tsx`（编辑）

在现有 `a`、`img` 自定义组件基础上，新增 `h1`/`h2`/`h3`/`h4` 自定义渲染：

- 新增可选 prop：`onHeadings?: (headings: TocHeading[]) => void`
- 用一个 `useRef<TocHeading[]>` 收集本次渲染出现的标题（含 id、text、level）
- 用一个 `useRef<Record<string, number>>` 做 slug 去重计数：相同文本第二次出现时追加 `-1`、`-2`…（与 GitHub 一致）
- 两个 ref 在每次渲染前通过 `useMemo(() => { ... }, [content])` 重置，保证内容变化时重新收集
- 自定义 heading 组件：从 `children` 提取纯文本 → 用 `slugify` + 去重计数生成 `id` → 渲染对应 `hN`，带 `id` 与 `scroll-mt-24`（避开 sticky header）→ push 到收集 ref
- 在 `useEffect` 中调用 `onHeadings(collectedRef.current)`，把标题列表回传给父组件

`children` 提取文本：写一个小的递归 `nodeToText(node)` 处理 string/number/React 元素的 children。

这样 TOC 的标题 id 与正文渲染的 id 来自同一套逻辑，必然一致；回复里用的 `MarkdownRender` 不传 `onHeadings`，行为不受影响（标题照常带 id，无副作用）。

## 3. `frontend/src/components/Toc.tsx`（新建）

非 UI 原语的功能组件，放 `src/components/` 根目录（与 `MarkdownRender`、`EmptyState` 同级）。

```tsx
export interface TocProps {
  headings: TocHeading[]
  className?: string
}
```

行为：
- 标题数 < 2 时不渲染（目录无意义）
- 用 `useEffect` + `IntersectionObserver` 观察所有 `#id` 标题元素，rootMargin 设为 `0px 0px -70% 0px`（让标题进入视口上部时判定为“当前章节”），维护 `activeId` state
- 点击条目：`document.getElementById(id)?.scrollIntoView({ behavior: 'smooth', block: 'start' })`；同时立即设 `activeId` 为该 id（避免滚动过程中高亮跳动）
- 按 `level` 缩进：`level 2` → `pl-3`，`level 3` → `pl-6`，`level 4` → `pl-9`；`level 1` 不缩进
- 激活项用 `text-primary-600 font-medium border-l-2 border-primary-600`；非激活项 `text-gray-500 hover:text-primary-600`
- 容器：`sticky top-20`（80px，清开 `h-16` sticky header 并留 16px 余量），`max-h-[calc(100vh-6rem)] overflow-y-auto`，列表右侧加细边框 `border-l border-gray-100`
- 标题“目录”二字 + `List` 图标（lucide-react，已装）

观察者需处理：标题元素可能尚未渲染（异步），在 effect 依赖 `headings` 重新建立 observer；`disconnect` 清理。

## 4. `frontend/src/pages/Forum/TopicDetail.tsx`（编辑）

- 顶部新增 import：`Toc`、`TocHeading` 类型
- 新增 state：`const [headings, setHeadings] = useState<TocHeading[]>([])`
- `topic.type === 'article'` 时，把整个返回结构从单列改为双列：

```tsx
return (
  <div className="flex gap-6 w-full">
    {/* 主内容列 */}
    <div className="flex flex-col gap-6 flex-1 min-w-0">
      <Button>返回</Button>
      <Card>...正文...</Card>
      <Card>...回复列表...</Card>
      <Card>...回复框...</Card>
    </div>
    {/* 右侧粘性目录（仅大屏） */}
    {topic.type === 'article' && headings.length >= 2 && (
      <aside className="hidden lg:block w-56 shrink-0">
        <Toc headings={headings} />
      </aside>
    )}
  </div>
)
```

- 正文 `<MarkdownRender content={topic.content} onHeadings={setHeadings} />`（仅文章传 `onHeadings`，但传了也无害；为简洁，统一传）
- 非 article 类型：`topic.type !== 'article'` 时保持原有单列结构（用一个条件分支或始终走双列但右侧栏仅在 article 且有足够标题时渲染——采用后者更简洁，非文章时右侧栏不渲染即等同单列）

为避免大改 JSX 结构，采用“始终双列容器 + 条件渲染右侧栏”的写法：`flex gap-6` 容器，主列 `flex-1 min-w-0`，右侧栏条件渲染。非文章时无右侧栏，主列占满，视觉与现状一致。

`min-w-0` 关键：防止 flex 子项内容（长 markdown/代码块）撑破布局。

## 不做的事 / 边界

- 不新增依赖（不加 `rehype-slug` / `rehype-autolink-headings`）
- 不改路由、不改 `MainLayout`
- 社区详情页 `Community/Detail.tsx` 本次不动（用户选择“仅文章类型”）
- 回复区 `MarkdownRender` 不受影响（不传 `onHeadings`，标题照常渲染带 id 但不触发回调副作用）
- 小屏（<1024px）不显示目录，正文正常阅读

## 验证方式

1. `npm run lint`（`tsc --noEmit`）确认无类型错误
2. `npm run dev` 打开一篇文章（含多级标题、含重名标题、含中文标题）：
   - 右侧出现目录，层级缩进正确
   - 点击条目平滑滚动到对应章节，标题不被 sticky header 遮挡
   - 滚动正文，目录高亮跟随当前章节
   - 缩窗到 <1024px，目录消失
3. 打开非文章类型帖子（讨论/问答/资源）确认无双列、无目录
4. 检查回复区 markdown 渲染未受影响
